# Writing rules for this project

Never use an em dash (—) in any text you write for this project. This
applies to marketing copy, code comments, commit messages, documentation,
and your own conversational responses while working in this repo, with no
exceptions and no expiration. Use a period, a comma, a colon, or a plain
hyphen instead, whichever reads most naturally. See
[BRAND_GUIDELINES.md](./BRAND_GUIDELINES.md) for the full voice and tone
guide, and [CLAUDE.md](./CLAUDE.md) for SEO and technical conventions.
